## Notes vs. blog posts

A blog post is meant to be published — you write it with a reader in mind. A note is first of all for yourself: write it down now, tidy it later.

So notes are allowed to be:

- only a few lines
- without a conclusion
- heavily rewritten later
- just a link to an external source

## Status

Every note has a status:

- `in-progress`: being written
- `incomplete`: missing something
- `ready`: tidied up and readable
- `archived`: kept for the record, no longer updated

## Tags

Tags connect notes across topics. Once there are enough notes, the tag index becomes more useful than scrolling by date.
