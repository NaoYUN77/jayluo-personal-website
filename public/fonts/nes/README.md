# Pixel fonts

- Press Start 2P: extracted from `design/nes-style.html`; Copyright 2011 The Press Start 2P Project Authors. See `OFL-Press-Start-2P.txt`.
- Fusion Pixel: full 12px monospaced Simplified Chinese font, release 2026.11.10 from https://github.com/TakWolf/fusion-pixel-font. This replaces the reference page's demonstration subset so blog content has full Chinese coverage. See `fusion-licenses/` for the font and inherited source licenses.

Both fonts are served locally. No external font service is required.
